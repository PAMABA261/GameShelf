# GameShelf

A social backlog tracker that helps gamers organize their library, write Markdown guides, and support creators. Built for the RevenueCat Shipaton 2026.

## Tech Stack
- **Frontend:** Flutter
- **Backend & Auth:** Supabase
- **Monetization:** RevenueCat
- **Data:** IGDB API

## How to Run the Project

### Prerequisites
- [Flutter SDK](https://docs.flutter.dev/get-started/install) installed (version 3.11.1 or higher).
- An Android/iOS emulator or a physical device connected.

### Steps
1. Clone the repository:
   git clone https://github.com/PAMABA261/GameShelf.git

2. Navigate to the project directory:
   cd GameShelf

3. Install the dependencies:
   flutter pub get

4. Run the app:
   flutter run

*(Note: API keys for Supabase and RevenueCat are included in the source code for testing purposes during the hackathon evaluation).*
